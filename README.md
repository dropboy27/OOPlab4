# Лабораторная работа 4 — фигуры вариант 1

Треугольник, квадрат и пятиугольник с общим интерфейсом и коллекцией на динамическом массиве. Программа выводит фигуры, их особые характеристики и суммарную площадь. Написано 15 тестов Google Test.

## Сборка проекта

Из корня проекта:

```bash
mkdir -p build
cd build
cmake ..
make
```

## Запуск

Из папки `build`:

```bash
./lab4_app
```

## Запуск тестов

Из папки `build`:

```bash
./run_tests
```

## После изменения кода

Из папки `build`:

```bash
make
./run_tests
```

## Проверка памяти

Из корня проекта для Linux с GCC или Clang:

```bash
mkdir -p build-asan
cd build-asan
cmake .. -DENABLE_SANITIZERS=ON -DCMAKE_BUILD_TYPE=Debug
make
ASAN_OPTIONS=detect_leaks=1 ./run_tests
```

## Структура и классы

`include/` содержит заголовки, `src/` — реализации и `main.cpp`, `tests/` — тесты. `CMakeLists.txt` и `README.md` находятся в корне. Папки `build/` и `build-asan/` не добавляются в Git.

| Класс | Назначение |
|---|---|
| `Point` | Две координаты вершины |
| `Figure` | Абстрактный интерфейс для площади, центра, ввода, вывода и копирования |
| `Triangle` | Три вершины и проверка равносторонности |
| `Square` | Четыре вершины и длина стороны |
| `Pentagon` | Пять вершин и проверка правильности |
| `FigureCollection` | Массив указателей на фигуры и правило пяти |

Общие методы виртуальные, чтобы через `Figure*` вызывать реализацию нужного наследника. Методы чтения состояния помечены `const`. Особые методы вызываются после `dynamic_cast`. Площадь вычисляется по формуле шнурка, центр — как среднее координат вершин. Вершины задаются в порядке обхода.

Коллекция владеет добавленными объектами, созданными через `new`, и удаляет их через виртуальный деструктор `Figure`. Один указатель нельзя добавить дважды. При копировании создаются отдельные фигуры через `clone`, при перемещении передаётся владение массивом.

## Формат ввода и вывода

`operator<<` вызывает `print`, `operator>>` вызывает `read`. Ввод принимает полный формат вывода. Пример для треугольника:

```text
Triangle: (0, 0) (4, 0) (0, 3)
Center: (1.33333, 1)
Area: 6
```

Для квадрата используется имя `Square:` и четыре вершины, для пятиугольника — `Pentagon:` и пять вершин. Сохраняются только вершины, центр и площадь вычисляются заново. При неверном формате устанавливается `failbit`, фигура сохраняет прежние координаты.

`operator==` сравнивает площади с точностью `1e-6`, преобразование к `double` возвращает площадь.
